## ✨ Tentang Tema

**WebJTI Theme** adalah tema WordPress yang dirancang khusus untuk kebutuhan platform akademik WebJTI. Tema ini dibangun dengan struktur yang rapi dan ringan, cocok digunakan sebagai fondasi situs institusi pendidikan maupun jurusan.

## 🚀 Instalasi

1. 🟡 Unduh atau _clone_ repositori ini
2. 🟡 Masuk ke dashboard WordPress → **Appearance → Themes → Add New → Upload Theme**
3. 🟡 Unggah folder/berkas `.zip` tema WebJTI
4. 🟡 Klik **Activate** untuk mengaktifkan tema
5. 🟡 Selesai — tema siap digunakan 🎉
